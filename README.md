# Version 1.0.0
ポモドーロタイマーアプリの初期リリースです。

## 機能
- **タイマー表示**: 残り時間をMM:SS形式で大きく表示します。
- **時間選択**: 25分、30分、40分、50分、60分のボタンで時間を設定できます。
- **コントロール**: 開始、一時停止、リセットボタンでタイマーを操作できます。
- **通知**: タイマー終了時にアラーム音でお知らせします。

## 実行方法
`npm run dev` コマンドでローカルサーバーを起動してください。
